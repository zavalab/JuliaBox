# MultiScaleMPC

Spatial and temporal multi-scale mixed-integer MPC case studies solved with dual dynamic programming.

## Contents
- `Spatial.jl`, `Spatial_sub.jl`, `Spatial_figure.m`: spatial case study and figure
- `Temporal.jl`, `Temporal_figure.m`: temporal case study and figure

## Reference
This code accompanies the paper:

Ranjeet Kumar, Michael J. Wenzel, Mohammad N. ElBsat, Michael J. Risbeck, Kirk H. Drees, and Victor M. Zavala. "Dual dynamic programming for multi-scale mixed-integer MPC." *Computers & Chemical Engineering* 148 (2021): 107265. https://doi.org/10.1016/j.compchemeng.2021.107265

Preprint: https://arxiv.org/abs/2007.10149
