# FairnessMeasures

Fairness measures (Nash, max-min, α-fair, entropy, social welfare) for nutrient balancing and power allocation case studies.

## Contents
- `NutrientBalancing/`: nutrient balancing case study, one folder per fairness measure
- `PowerAllocation/`: power allocation case studies (`caseI/`, `caseII/`)

## Reference
This code accompanies the paper:
