# SensitivityNMPC

Exponential decay of sensitivity in dynamic optimization under controllability and observability, illustrated with linear and nonlinear model predictive control problems.

## Contents
- `cstudy_include.jl`: linear and nonlinear optimal control models
- `cstudy_run.jl`: solves the reference and perturbed problems and plots the sensitivities

## Reference
This code accompanies the paper:
