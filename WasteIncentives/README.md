# WasteIncentives

Economic and environmental analysis of incentives (RINs, RECs, nutrient credits) for value recovery from livestock waste in Wisconsin.

## Contents
- `pure_economic/`: no incentives
- `rin_incentives/`, `rec_incentives/`, `nutrient_credits/`, `all_incentives/`: RIN, REC, nutrient credit, and combined incentives
- `value_analysis/`: value analysis
