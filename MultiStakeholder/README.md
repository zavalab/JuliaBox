# MultiStakeholder

Multi-stakeholder decision-making with CVaR-based conflict resolution: two- and three-objective examples and a facility location case study.

See `README.txt` for how to run the examples (`two_objectives_v2.jl`, `three_objectives2.jl`) and the facility location case study (`facility_location_problem3.jl`).

## Reference
This code accompanies the paper:

Alexander W. Dowling, Gerardo Ruiz-Mercado, and Victor M. Zavala. "A framework for multi-stakeholder decision-making and conflict resolution." *Computers & Chemical Engineering* 90 (2016): 136-150. https://doi.org/10.1016/j.compchemeng.2016.03.034
