# VirtualLinks

Electricity market clearing with virtual links that capture space-time load-shifting flexibility from data centers, and the remuneration of that flexibility.

## Contents
- `case_studies.ipynb`: case studies (spatial 7-bus system and IEEE 30-bus system)
- `pglib_opf_case30_ieee__api.m`: IEEE 30-bus data

## Reference
