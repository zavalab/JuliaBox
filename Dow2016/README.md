# Dow2016

Stochastic programming short course for Dow (2016): formulations, interior-point (PIPS-NLP, IPCluster), and dual decomposition (DSP) examples.

## Contents
- `stochprog/`: stochastic programming formulations (farmer and Gaussian examples)
- `IPM_examples/`: interior-point examples with PIPS-NLP and IPCluster, including a stochastic gas network (`DAT_PAPER/`)
- `DSP_examples/`: dual decomposition examples with DSP
