# Valladolid2017

Stochastic programming course at the University of Valladolid (2017): formulations, CSTR examples, and stochastic MILPs and NLPs with Plasmo, DSP, and PIPS-NLP.

## Contents
- `install_packages.ipynb`: package installation
- `Formulations/`: stochastic programming formulations
- `CSTR/`: deterministic, stochastic, and dynamic stochastic CSTR examples
- `StochMILP/`, `StochMILP2/`: stochastic MILPs with DSP, dual decomposition, and facility location
- `StochNLP/`, `StochNLP2/`: stochastic NLPs (PID controller tuning, gas pipelines) with Plasmo
