# ModularPlanning

Single- and multi-period investment planning with modular technologies under uncertainty, deterministic and stochastic.

## Contents
- `single_det.ipynb`: deterministic single-period planning
- `single_sto_case_*.ipynb`: stochastic single-period case studies
- `multi_sto_case_*.ipynb`: stochastic multi-period case studies
- `data for plots/`: data for the figures
