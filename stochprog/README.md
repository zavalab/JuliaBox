# stochprog

Stochastic programming tutorial notebooks: the farmer problem (deterministic, wait-and-see, CVaR, chance constraints, inference), Gaussian examples, and Ipopt and DSP examples.

## Contents
- `farmer*.ipynb`: farmer problem (deterministic, stochastic, wait-and-see, CVaR, chance constraint, inference, DSP)
- `ex1gauss*.ipynb`: Gaussian examples
- `ipoptex1.ipynb`: Ipopt example
