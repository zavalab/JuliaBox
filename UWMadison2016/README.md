# UWMadison2016

2016 UW–Madison short course on stochastic programming: formulations, interior-point (PIPS-NLP, IPCluster) and dual decomposition (DSP) examples, including a stochastic gas network.

## Contents
- `stochprog/`: stochastic programming formulations (farmer, Gaussian, and multistage inventory examples)
- `IPM_examples/`: interior-point examples with PIPS-NLP and IPCluster, including a stochastic gas network (`DAT_PAPER/`)
- `DSP_examples/`: dual decomposition examples with DSP
