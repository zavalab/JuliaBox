# MHEGasNetwork

Animations of moving horizon state estimation for a natural gas network:
- `base_case_estimation.gif`: base case
- `highly_dynamic_estimation.gif`: highly dynamic conditions

## Reference
This code accompanies the paper:

Jordan Jalving and Victor M. Zavala. "An Optimization-Based State Estimation Framework for Large-Scale Natural Gas Networks." *Industrial & Engineering Chemistry Research* 57, no. 17 (2018): 5966-5979. https://doi.org/10.1021/acs.iecr.7b04124
