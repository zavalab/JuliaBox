# SupplyPlanning

Deterministic and stochastic multi-site supply planning for drug products under uncertainty (synthetic data).

See `readme.txt`. The data files are synthetic because the data used in the paper are proprietary.

## Reference
This code accompanies the paper:

Apoorva M. Sampat, Ranjeet Kumar, Remya Pushpangatha Kurup, Kawa Chiu, Victor M. Saucedo, and Victor M. Zavala. "Multisite supply planning for drug products under uncertainty." *AIChE Journal* 67, no. 1 (2021): e17069. https://doi.org/10.1002/aic.17069
