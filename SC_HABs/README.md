# SC_HABs

Supply chain optimization of livestock waste management for spatiotemporal control of nutrient pollution and harmful algal blooms, coupled with the NEWS2 nutrient runoff and PROTECH algae models.

## Contents
- `Scenario I-update/`, `Scenario II-update/`, `Scenario III-update/`: scenarios, each with the supply chain model (`SC_OPT.jl`, `SC_Run.jl`), the NEWS2 nutrient runoff model (`NEWS2_Run.jl`), the PROTECH algae model (`PROTECH.jl`), data generators, and results
