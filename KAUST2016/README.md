# KAUST2016

Stochastic programming short course at KAUST (2016): formulations, PIPS-NLP, and IPCluster examples, including a stochastic gas network.

## Contents
- `stochprog/`: stochastic programming formulations (farmer and Gaussian examples)
- `PIPS_examples/`: PIPS-NLP examples, including a stochastic gas network (`DAT_PAPER/`)
- `IPCluster_examples/`: IPCluster examples
