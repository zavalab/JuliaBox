# CoordMarket

Coordinated market model for managing organic waste and its derived products, with simple examples and an Upper Yahara watershed case study.

## Contents
- `Simple_Systems.ipynb`: small illustrative systems
- `Upper Yahara Case/`: one folder per scenario, each with the market model (`market_model.jl`), the run script (`market_Run.jl`), a script to print results (`market_print.jl`), and the input data (`.csv`)
