# UWMadison2017

2017 UW–Madison short course on stochastic programming: formulations, stochastic MILPs (Plasmo, DSP, dual decomposition), and stochastic NLPs (PID tuning, gas pipelines, PIPS-NLP).

## Contents
- `install_packages.ipynb`: package installation
- `Formulations/`: stochastic programming formulations (farmer, Gaussian, multistage battery examples)
- `StochMILP/`: stochastic MILPs with Plasmo, Cbc, and DSP, dual decomposition, and facility location
- `StochNLP/`: stochastic NLPs (PID controller tuning, gas pipelines) with Plasmo, Ipopt, and PIPS-NLP
