# FlexQuantVL

Quantifying space-time load-shifting flexibility in electricity markets with virtual links, using a KKT-based formulation of the market clearing problem (`linear_kkt.jl`).

## Reference
This code accompanies the paper:

Weiqi Zhang and Victor M. Zavala. "Quantifying space-time load shifting flexibility in electricity markets." *Computers & Chemical Engineering* 177 (2023): 108338. https://doi.org/10.1016/j.compchemeng.2023.108338

Preprint: https://arxiv.org/abs/2303.10217
