# PSCC2020

Market clearing with virtual links that capture space-time load-shifting flexibility from networks of data centers.

## Contents
- `3bus_case.ipynb`: 3-bus case study
- `ieee_30_case.jl`: IEEE 30-bus case study
- `space_time.ipynb`, `5times.ipynb`: space-time shifting examples

## Reference
This code accompanies the paper:

Weiqi Zhang, Line A. Roald, Andrew A. Chien, John R. Birge, and Victor M. Zavala. "Flexibility from networks of data centers: A market clearing formulation with virtual links." *Electric Power Systems Research* 189 (2020): 106723. https://doi.org/10.1016/j.epsr.2020.106723

Preprint: https://arxiv.org/abs/1910.05443
