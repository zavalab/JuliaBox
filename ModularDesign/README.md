# ModularDesign

Optimal design of modular processes and supply chains using standard and spatial superstructures.

## Contents
- `Design_with_Superstructure.ipynb`: design with a standard superstructure
- `Design_with_SpatialSuperstructure.ipynb`: design with a spatial superstructure
