# StorageVirtualLink

Pricing and remunerating electricity storage flexibility with virtual links: IEEE 30-bus case studies.

## Contents
- `case_study_1.ipynb`, `case_study_2.ipynb`: case studies
- `pglib_opf_case30_ieee__api.m`: IEEE 30-bus data
- `plotjl.ipynb`: figures

## Reference
This code accompanies the paper:

Weiqi Zhang, Philip A. Tominac, and Victor M. Zavala. "Pricing and remunerating electricity storage flexibility using virtual links." *Computers & Chemical Engineering* 168 (2022): 108019. https://doi.org/10.1016/j.compchemeng.2022.108019

Preprint: https://arxiv.org/abs/2204.07281
