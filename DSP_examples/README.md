# DSP_examples

The stochastic farmer problem modeled with StructJuMP and solved with the DSP dual decomposition solver.

## Contents
- `Farmer_Example/farmer_struct.jl`: StructJuMP model
- `Farmer_Example/farmer_stoch.ipynb`: notebook that builds and solves the problem
