# Plastic_SC

This directory contains the Julia code (located at each folder with different formulations applied) and data used in the paper "A Fairness-Guided Supply Chain Framework for Polyester Production from Biomass" from Wang and Zavala.

## Reference
This code accompanies the paper:

Bo-Xun Wang and Victor M. Zavala. "A fairness-guided supply chain framework for polyester production from biomass." *Computers & Chemical Engineering* 206 (2026): 109504. https://doi.org/10.1016/j.compchemeng.2025.109504
