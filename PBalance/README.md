# PBalance

Phosphorus balance model across the sectors of the dairy supply chain: environment, mining, chemical, soil, crop production and processing, food distribution, urban, wastewater treatment, manure management, and dairy livestock.

## Contents
- `nexus_code.jl`: phosphorus balance model (written for Julia 0.6)
- `data.xlsx`: input data
