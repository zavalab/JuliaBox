# SNGO

Examples for SNGO, a scalable global optimization algorithm for stochastic nonlinear programs: optimal PID controller tuning and parameter estimation for microbial growth models, compared with SCIP.

## Contents
- `examples/`: case studies and results (see `examples/README` for how to run them; the examples can be checked with SCIP)
