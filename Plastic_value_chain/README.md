# Plastic_value_chain

Value chain optimization of infrastructures for thermochemical upcycling of post-consumer plastic waste (sorting, pyrolysis, steam cracking, and LDPE/PP production), with LP and MIP models for four scenarios.

## Contents
- `I/`, `II/`, `III/`, `IV/`: scenarios, each with an LP model (`LP.jl`), a MIP model (`MIP.jl`), and data (nodes, products, supplies, demands, technologies, sites, capacities)
