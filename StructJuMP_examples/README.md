# StructJuMP_examples

Two-stage stochastic energy system model built with StructJuMP and solved with PIPS, DSP, and Gurobi (example by Alex Dowling, 2016).

## Contents
- `energy_system_setup.jl`: model and data
- `energy_system_pips.jl`: solution with PIPS
- `energy_system_dsp.jl`: solution with DSP
- `energy_system_gurobi.jl`: solution of the extensive form with Gurobi
