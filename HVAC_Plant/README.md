# HVAC_Plant

Animations comparing deterministic and stochastic model predictive control of a central HVAC plant.

## Contents
- `deterministic_animation.gif`: deterministic MPC
- `stochastic_animation.gif`: stochastic MPC

## Reference
This code accompanies the paper:

Ranjeet Kumar, Michael J. Wenzel, Mohammad N. ElBsat, Michael J. Risbeck, Kirk H. Drees, and Victor M. Zavala. "Stochastic model predictive control for central HVAC plants." *Journal of Process Control* 90 (2020): 1-17. https://doi.org/10.1016/j.jprocont.2020.03.015

Preprint: https://arxiv.org/abs/2002.10065
