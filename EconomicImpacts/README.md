# EconomicImpacts

Market model for valuing reductions of economic impacts of nutrient pollution from livestock waste in the Upper Yahara watershed, with sensitivity analysis.

See `readme.txt` for how to run the market model and the sensitivity analysis (`sensitivity_analysis/`).

## Reference
This code accompanies the paper:

Apoorva M. Sampat, Andrea Hicks, Gerardo J. Ruiz-Mercado, and Victor M. Zavala. "Valuing economic impact reductions of nutrient pollution from livestock waste." *Resources, Conservation and Recycling* 164 (2021): 105199. https://doi.org/10.1016/j.resconrec.2020.105199

Preprint: https://doi.org/10.26434/chemrxiv.12324188
