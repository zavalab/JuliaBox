# C6C8Recovery

Supply chain model for recovering biogas and medium-chain fatty acids (C6/C8) from organic waste, with base cases and sensitivity analyses on biogas price, social cost of carbon, and yields.

See `Read_Me.txt` for a description of the models, input data, and the folder for each case study. All data and results are summarized in `Data_results.xlsx`.
