# ShinThesis

Code for the case studies in Sungho Shin's PhD thesis, Graph-Structured Nonlinear Programming: Properties and Algorithms (UW–Madison, 2021); the maintained version is at sshin23/shin-thesis-code.

This code is outdated. The maintained version is at https://github.com/sshin23/shin-thesis-code.

## Contents
- `run_case_study.jl`, `case_study_include.jl`: case studies
- `pglib_opf_case*.m`, `pos.csv`, `pos.jl`, `elist.jl`, `elist/`: power network data

## Reference
Sungho Shin. *Graph-Structured Nonlinear Programming: Properties and Algorithms*. PhD thesis, University of Wisconsin–Madison, 2021. https://www.proquest.com/docview/2544907352
