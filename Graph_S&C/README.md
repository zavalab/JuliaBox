# Graph_S&C

Solution of large-scale supply chain models using graph sampling and coarsening, with time and memory tests against Gurobi.

See `readme.txt`: `time_test/` derives the upper and lower bounds for the large-scale case study, and `memory_test/` compares the memory use of Gurobi and graph sampling and coarsening.
