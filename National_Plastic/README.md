# National_Plastic

Value chain optimization of a national-scale thermochemical plastic waste upcycling infrastructure in the United States.

## Contents
- `MIP Cases/`, `CSC Cases/`: case studies
- `National_plastic_code.zip`: code

See also `readme.txt`.

## Reference
This code accompanies the paper:

Evan D. Erickson, Philip A. Tominac, Jiaze Ma, Horacio Aguirre-Villegas, and Victor M. Zavala. Preprint: https://doi.org/10.26434/chemrxiv-2023-96xng
