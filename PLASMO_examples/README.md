# PLASMO_examples

Early Plasmo.jl examples for graph-based modeling and optimization of natural gas pipeline networks.

## Contents
- `simple_model.ipynb`: a simple Plasmo.jl model
- `gas_pipeline.jl`, `gas_pipepline.ipynb`: a single gas pipeline
- `pipeline_network.ipynb`: a pipeline network
- `13_pipe_network/`: a 13-pipe gas network with data (`DAT_13pipe_GAS/`), results, and plotting script
- `src/`: supporting code
