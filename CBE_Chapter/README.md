# CBE_Chapter

Julia tutorials for the book chapter Optimization in Chemical and Biological Engineering Using Julia: JuMP, InfiniteOpt, and Plasmo tutorials and examples (blending, Gibbs reactor, controller tuning, dynamic parameter estimation, supply chain).

## Contents
- `JuMP_tutorial.jl`, `InfiniteOpt_tutorial.jl`, `Plasmo_tutorial.jl`: tutorials
- `Blending_Problem.jl`, `Gibbs_Reactor.jl`, `Controller_Tuning.jl`, `Dynamic_Parameter_Estimation.jl`, `Supply_Chain.jl`: examples

## References
These tutorials accompany the book chapter:

1. Joshua L. Pulsipher, David L. Cole, Jordan Jalving, and Victor M. Zavala. "Optimization in Chemical and Biological Engineering Using Julia." In *Introduction to Software for Chemical Engineers*, 774–806. CRC Press, 2025. https://doi.org/10.1201/9781003472360-27
2. Jordan Jalving and Victor M. Zavala. "Optimization in Chemical and Biological Engineering using Julia." In *Introduction to Software for Chemical Engineers*, 713–732. CRC Press, 2019. https://doi.org/10.1201/9780429451010-18
